# 가상 이동 설문: 문항과 분석 범위

**이 설문의 응답자 1,800명은 모두 프로그램이 생성한 가상 사례입니다.** 실제 사람의 응답이나 익명화 자료가 아닙니다.

## 연구 연습

- LCA: `응답자의 이동 태도 유형은 무엇인가?` — `att_` 8문항의 응답 유형을 기술한다.
- MCA: `응답자의 이동 서비스 선택 범주는 어떻게 함께 나타나는가?` — `choice_` 5문항의 범주 관계를 탐색한다.

두 질문은 별도 분석 경로다. MCA 지도를 LCA 계층의 원인이나 확인 결과로 쓰지 않는다. 이 예제로 현실 모집단의 효과, 미래 구매, 유의성, 표본설계 분산을 추정하지 않는다.

## 문항 구성

- `att_` 8개: 이동 비용, 편의, 환경, 안전, 디지털 서비스, 대중교통, 수단 전환, 차량 소유에 대한 동의 정도. 코드 1=전혀 그렇지 않다, 2=그렇지 않은 편, 3=그런 편, 4=매우 그렇다.
- `choice_` 5개: 출퇴근 수단, 선택 우선 기준, 고려 서비스, 주말 이동 목적, 정보 출처. 각 문항의 코드와 라벨은 `codebook.json`에 있다.
- 보조 8개: 합성 응답 번호, 성별, 연령대, 거주 지역, 소득 구간, 가구 차량, 통근일수, 교육용 가중 변수.

`income_group=99`는 응답 거절이며 코드북과 SAV 사용자 결측에 표시된다. 앱이 이를 자동으로 다른 값으로 재코딩하지 않도록 확인한다. `survey_weight`는 기본 따라하기에서 쓰지 않는다.
