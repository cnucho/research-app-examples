# 정책효과 분석 연습과제: 데이터 안내

**모든 관측값·개인·지역·사업 규칙·문항은 가상이다.** 실제 응답이나 행정기록을 익명처리한 자료가 아니다. 실제 공개자료는 파일 구성과 항목 설계의 구조 참고에만 사용했다. 계산 결과를 현실 사업의 성과로 인용하지 않는다.

## 자료를 사용하는 순서

1. 압축파일 최상위의 `README_KO.md`와 `PRACTICE_PROBLEMS_KO.md`를 읽고 사례 하나와 변형 하나를 고른다.
2. 선택한 `<사례>/<변형>/README.md`에서 대상·시점·관측 단위·파일 관계를 확인한다.
3. `codebook.csv`, `datapackage.json`, 필요한 문항과 값 라벨을 읽고 분석계획을 세운다.
4. `data/`의 CSV 또는 SAV 중 한 형식으로 실제 관측자료를 읽는다. 사용하는 분석 도구는 자유다.
5. 자료 준비와 계산을 실행하고, 선택한 비교전략·처리 기록·결과·불확실성과 한계를 제출한다.

이 안내와 데이터는 특정 서비스의 계정이나 접속 없이 사용할 수 있다. 추가 도구 사용 예시는 최상위 `OPTIONAL_TOOLS_KO.md`에 있다.

## 사례와 관측 단위

| 사례 폴더 | 정책문제 | 자료 구조 |
| --- | --- | --- |
| `c01_heat_shelters` | 무더위쉼터 운영 확대와 온열질환 신고 | 동일 지역을 여러 해 관측한 패널·정책 이력·시설대장 |
| `c02_youth_transport` | 청년 교통·구직지원과 월 근로소득 | 각 반기에 다른 사람을 조사한 반복횡단면·지역 정책 이력 |
| `c03_training` | 디지털 재취업교육과 후속 근로소득 | 참여 전 조사·사업기록·6개월 후 추적자료 |
| `c04_home_insulation` | 주거환경 개선지원과 전력사용량 | 신청 점수·지원 규칙·수혜 기록·전력사용 기록 |
| `c05_digital_service` | 디지털 민원교육·자기효능감·과제 수행 | 사전 특성·배정·중간 설문·후속 평가 |
| `c06_heat_safety` | 폭염 안전교육 시간·옥외근무·열부담 | 기초 환경·교육기록·동일 30일의 후속 관측 |

각 사례의 `v01`, `v02`는 별도의 가상 자료 세트다. 서로 추가 표본이나 연속 조사처럼 합치지 않는다. 파일별 행수와 변수는 각 세트의 설명서를 확인한다. 같은 표의 CSV와 SAV도 합치지 않는다.

## 세트별 설명 파일

| 파일 | 내용 |
| --- | --- |
| `README.md` | 정책질문, 대상, 기간, 관측 단위, 자료 결합 관계 |
| `datapackage.json` | 파일 목록, 자료형, 기본키·외래키, 행열 수, 데이터 해시 |
| `codebook.csv`, `codebook.json` | 변수명·설명·단위·코드·결측·측정시점·파생식 |
| `questionnaire.csv` | 새로 작성한 문항·응답 형식·대상·건너뛰기 조건 |
| `value_labels.csv` | 범주 코드별 의미와 사용자 결측 여부 |
| `source_crosswalk.csv`, `sources.json` | 실제 자료와 구조가 대응하는 부분, 개념 차용·자체 설계의 구분 |

CSV는 UTF-8 BOM이다. 코드북에 맞춰 자료형을 적용하고 문자열 ID의 앞자리 0을 보존한다. SAV는 변수·값 라벨과 사용자 결측 정보를 포함한다. 결측코드는 해당 변수의 정의를 확인해 처리하고, 표본 제외나 대체는 근거와 바뀐 관측 수를 기록한다.

파일을 합칠 때는 키와 일대일·다대일 관계, 중복·미결합 수, 결합 전후 행수를 확인한다. 변수 계산은 원변수와 계산식·단위·적용 범위를 남기고 실제 값 몇 개를 대조한다. 원본을 보존하고 분석용 사본을 만든다.

## 버전과 무결성

기반 데이터는 `policy-benchmark-v1`이며 이 학생용 배포는 `policy-analysis-student-v1` 개정 2다. 모든 관측자료, 코드북, 문항, 값 라벨, 출처 및 데이터 descriptor는 기반 배포본의 바이트를 보존한다. 이 데이터 안내와 12개 사례 README는 독립적인 수업 과제로 사용할 수 있도록 편집했다.

`manifest.json`은 학생용 데이터 폴더의 현재 파일 해시를 기록한다. 원래 배포본의 manifest와 등록부는 압축파일 최상위 `provenance/original-input-manifest.json`, `provenance/original-input-registry.json`에, 수정 경로와 전후 해시는 `student-package.json`에 있다. `registry.json`은 사례별 README 해시만 갱신했으며 다른 자료 목록과 호환성 이력은 보존한다. 호환성 이력이 과제에서 사용할 소프트웨어를 지정하는 것은 아니다.

파일 해시 일치와 계산의 정합성은 분석전략이나 인과적 해석의 타당성에 대한 판정이 아니다. 제출 기준과 평가는 최상위 학생 안내와 문제집을 따른다.
