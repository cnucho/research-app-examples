# 선택 안내: 분석 도구와 대화형 도움 활용

과제의 필수 설명과 평가기준은 [학생 안내](README_KO.md)와 [문제집](PRACTICE_PROBLEMS_KO.md)에 모두 있다. 이 문서는 도구 선택이나 추가 실습에 참고하는 부록이다. 특정 소프트웨어의 사용, 계정 가입, AI와의 대화는 필수 과제가 아니다.

## 1. 자신이 사용할 도구 선택

R, Stata, SPSS, Python 등 익숙한 환경에서 제공된 CSV 또는 SAV를 읽고 작업할 수 있다. 사용할 기능이 선택한 연구설계에 맞는지, 필요한 진단과 불확실성 계산을 지원하는지, 실제 설정과 출력 기록을 남길 수 있는지 확인한다. 모든 도구가 모든 방법과 같은 기본 설정을 제공한다고 가정하지 않는다.

GUI를 사용하면 클릭 순서와 중요한 옵션, 실행 결과를 남긴다. 명령어를 사용하면 코드나 syntax, 버전과 시드를 남긴다. 다른 사람이 같은 조건을 적용할 수 있도록 기록하는 것이 공통 요건이다.

## 2. 대화형 분석 도움을 받을 때

AI를 활용한다면 정책질문과 자료 설명부터 제공할 수 있다. 아래 문장은 특정 앱에 종속되지 않는 선택 예시다.

> 이 과제에서 알고 싶은 것은 [정책 담당자의 질문]이다. 선택한 사례와 변형의 자료·코드북을 제공했다. 먼저 대상, 관측 단위, 조사시점과 파일 관계를 확인해 줘. 가능한 비교전략과 가정, 각 전략으로 답할 수 있는 범위를 설명해 줘. 결합과 변수 계산을 하면 규칙과 확인 기록을 남겨 줘. 실제 계산한 결과를 바탕으로 표·그림과 재현자료를 만들고, 정책적 결론의 한계를 설명해 줘.

AI의 제안은 학생이 이해하고 검토할 대상이다. 실제 실행한 계산인지, 표본·단위·변수 정의가 맞는지, 요약문과 상세 결과가 같은 수치를 사용하는지 확인한다. 도구가 지원하지 않아 수행하지 못한 작업은 미완료로 기록한다. 수업의 AI 이용 방침이 있으면 그 방침을 따른다.

## 3. MethodIQ Policy Analysis를 선택하는 경우

MethodIQ Policy Analysis는 이 과제에 활용할 수 있도록 개발 중인 대화형 분석 도구다. 접근 권한이 있고 선택한 분석을 지원하는 환경이라면, 같은 자료와 정책질문을 제공해 분석대안 설명, 자료 처리, R 계산, 결과 정리 과정을 진행할 수 있다. 지원 범위와 현재 이용 가능 여부는 해당 서비스에서 확인한다. 과제 수행을 위해 이 서비스를 사용할 필요는 없다.

자료를 여러 번 나누어 제공할 때는 먼저 전체 파일 목록과 관측 단위를 확인하도록 요청할 수 있다. 방법의 선택 이유, 결합 전후 행수, 새 변수의 계산식, 진단 결과, 내려받을 수 있는 실제 계산 기록을 확인한다. 앱에서 파일이 출력되지 않았거나 계산이 완료되지 않았다면 과제의 해당 부분이 수행된 것으로 기록하지 않는다.

## 4. 선택 확장: 도구를 바꾸어 수행 경험 비교

원하면 한 도구로 마친 과제를 다른 도구로 다시 수행한다. 처음부터 어느 도구가 편리할 것이라는 결론을 정하지 말고 다음을 기록한다.

| 비교할 항목 | 기록할 내용 |
| --- | --- |
| 자료 준비 | 읽기·결합·변수 계산에 필요한 작업과 걸린 시간 |
| 분석 선택 | 대안과 가정, 선택 옵션을 이해하고 수정하기 쉬웠는지 |
| 오류 확인 | 자료·설정 오류를 발견하고 바로잡은 과정 |
| 결과 이해 | 정책질문에 대한 답, 불확실성·한계, 표와 그림의 명확성 |
| 재현 | 코드·syntax·절차·출력 기록을 확보하고 다시 실행할 수 있었는지 |
| 수치 대조 | 같은 표본·변수·모형·설정에서 결과가 일치하는지 |

도구 간 결과가 다르면 먼저 표본, 결측 처리, 가중치, 모형과 추정 대상, 표준오차·구간 설정을 대조한다. 실제 수행 기록을 근거로 편리한 점과 한계를 함께 평가한다. 이 확장 실습은 수업에서 별도로 지정하지 않는 한 필수 제출이나 가산점 요건이 아니다.
