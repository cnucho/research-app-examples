정책효과 분석 연습과제

정책 담당자의 질문을 읽고, 제공된 데이터와 설명서를 바탕으로 분석한 뒤, 근거와 한계를 갖춘 답을 제출한다. 사용하는 분석 도구는 자유다.

이 자료 묶음만으로 과제를 수행할 수 있다. 특정 앱 가입이나 AI 사용은 필요하지 않다. 데이터는 모두 가상이며 실제 정책의 성과를 나타내지 않는다.
PDF 과제집 열기학생 안내문제집 원문제출 양식

시작 순서

  1. 수업에서 지정한 사례와 변형을 선택한다. 지정이 없으면 아래 여섯 사례 중 하나를 고른다.
  2. 해당 user/사례/변형/ 폴더의 README·코드북·자료 설명을 읽는다.
  3. 정책질문과 비교전략을 정하고 CSV 또는 SAV로 계산한다.
  4. 정책 메모, 표·그림, 자료 처리 기록과 재현자료를 제출한다.

사례마다 v01·v02 두 독립 자료 세트가 있다. 한 변형만 선택해 시작한다. 전체는 12세트, 관측자료 CSV 38개와 같은 표의 SAV 38개다. 형식이나 변형을 추가 표본처럼 이어 붙이지 않는다.

제출과 평가

정책 메모 1~2쪽, 분석 부록, 자료 처리 기록, 실제 실행한 코드·syntax 또는 GUI 절차와 결과, 분석 선택·수정 기록을 제출한다. 질문·자료·비교전략·계산·해석·재현성이 평가 대상이다. 특정 도구 사용이나 유의한 결과 자체에는 점수를 주지 않는다.

추가로 도구 사용을 비교하고 싶다면 선택 도구 안내를 읽는다. 필수 과제 설명은 PDF 과제집과 학생 안내에 모두 있다.
