# Vendored metadata schemas

`tabular-data-package.json` and `table-schema.json` are the Frictionless v1
published JSON Schemas, serialized compactly without semantic changes.

- Specification: https://specs.frictionlessdata.io/
- Source repository: https://github.com/frictionlessdata/specs
- Compiled site revision: `a9c7fe2c23687267b52a5395d369b8d50d1ce5c5` (`v1-site`).
- Source specification revision: `16ef8f781ccc0a099ae7a268591f45fe77e87e78` (`v1`).
- License: public domain / Unlicense; see `FRICTIONLESS-LICENSE.md`.
- Checked: 2026-11-16.

These vendored schemas let verification run offline. `registry.schema.json`
is this catalog's small application schema, under the repository MIT license.
Per-field provenance, units, value labels and explicit numeric missing codes
are documented extensions. They do not alter the v1 core definition.
